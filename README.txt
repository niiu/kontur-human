Kontur — человеческая болванка для Blender 4.2 и новее (в том числе 5.x)

Установка
1. Blender → Edit → Preferences → Add-ons.
2. Стрелка справа сверху → Install from Disk…
3. Выбери kontur_human.zip, не распаковывая.
4. Включи аддон Kontur.

Как пользоваться
1. В 3D-виде нажми N.
2. Вкладка Kontur.
3. Пресет или ползунки: рост, голова, плечи, грудная клетка, талия, бёдра, грудь, руки, ноги.
4. А-поза или Т-поза. Пальцы можно выключить — будет варежка.
5. «Создать человека». Фигура встаёт на 3D-курсор.
6. Скелет уже с весами. Выбери арматуру, режим позы, крути кости. Сгиб руки и ноги — вращение по X.
7. «Пересобрать» заново строит выбранного человека текущими ползунками и стирает лепку и позу.
8. «Сплавить» делает один меш. «Пальцы» в сетке мельче и держит пальцы раздельными, «Крупно» быстрее.
9. Без сплавления куски лежат в одном объекте: в режиме редактирования Mesh → Separate → By Loose Parts.

Это база для лепки и анимации, не финальная топология под лицо крупным планом.
