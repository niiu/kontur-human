# Kontur

Аддон для Blender: человеческая болванка с пропорциями, скелетом и весами. Blender 4.2 и новее, включая 5.x.

Не финальная топология под крупный план лица, а база, которую можно лепить и анимировать.

## Установка

1. Code → Download ZIP.
2. Blender → Edit → Preferences → Add-ons.
3. Стрелка справа сверху → Install from Disk… и выбери скачанный zip. Распаковывать не нужно.
4. Включи **Kontur**.

## Как пользоваться

1. В 3D-виде нажми `N`.
2. Вкладка **Kontur**.
3. Пресет или ползунки: рост, голова, плечи, грудная клетка, талия, бёдра, грудь, руки, ноги.
4. А-поза или Т-поза. Пальцы можно выключить — будет варежка.
5. **Создать человека**. Фигура встаёт на 3D-курсор.
6. Скелет уже с весами. Режим позы, сгиб руки и ноги — вращение по локальной X.
7. **Пересобрать** строит выбранного человека заново и стирает лепку и позу.

«Сплавить» делает один меш. Сетка «Пальцы» мельче и держит пальцы раздельными, «Крупно» быстрее. Без сплавления куски можно разделить: Edit Mode → Mesh → Separate → By Loose Parts.

Кости подписаны `.L` / `.R`.
